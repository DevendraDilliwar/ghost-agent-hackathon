## 🚀 How to Run the Live Demo on Your Computer

### Step 1: Launch the Tally Legacy ERP Simulator
In your first terminal:
```bash
npm run demo:tally
```
*A retro TallyPrime accounting voucher window will open on screen.*

### Step 2: Launch NoMCP Universal Worker
In your second terminal:
```bash
npm run dev
```

### Step 3: Trigger the Universal Task
1. In NoMCP, click the **Voice Prompt** microphone button (or select the **`🇮🇳 Tally Invoice`** quick prompt chip).
2. Click **Execute Universal Task**.
3. Watch NoMCP:
   - Ground the Tally inputs using **SAM 3.1**
   - Plan with **Muse Spark**
   - Execute voucher entries
   - Verify completion with **Muse Wonder PRISM**!
